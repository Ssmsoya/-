# WAYPOINT — панель путешественника

Практическое задание №2. Адаптивный сайт на HTML, CSS и ванильном JavaScript.

## Запуск

**Быстро:** откройте `index.html` двойным кликом. В HTML встроена рабочая копия JavaScript для запуска через `file://`.

**Для разработки и проверки ES-модулей:** откройте папку в VS Code, запустите Live Server. Исходники с `export`/`import` находятся в `js/`. Файл `index.html` содержит собранную из этих модулей копию скрипта, чтобы работать и без сервера. После изменения файлов в `js/` необходимо обновить встроенный скрипт в `index.html`.

## Функции

- Три независимых виджета: список дел, погода и конвертер валют.
- Добавление (не более одного виджета каждого типа), удаление, сворачивание.
- Перетаскивание карточек за заголовок на компьютере; порядок сохраняется.
- Список дел: добавить, отметить выполнение, удалить.
- Погода: поиск любого города через геокодирование Open-Meteo; погода через Forecast API.
- Валюты: список поддерживаемых валют загружается из Frankfurter, можно менять пару, сумму и направление обмена.
- Загрузка, ошибки и повтор запроса. При недоступности сети реальные данные не подменяются фиктивными.
- localStorage сохраняет порядок карточек, задачи, выбранный город, валюты и сумму. Ошибки localStorage не останавливают сайт.
- Адаптивная сетка: три колонки на широком экране, две на среднем, одна на узком.

## Внешние API

1. Open-Meteo Geocoding: `https://geocoding-api.open-meteo.com/v1/search?name=Tallinn&count=10&language=ru&format=json`
2. Open-Meteo Forecast: `https://api.open-meteo.com/v1/forecast?latitude=59.437&longitude=24.7536&current=temperature_2m,relative_humidity_2m,apparent_temperature,weather_code,wind_speed_10m&timezone=auto`
3. Frankfurter: `https://api.frankfurter.dev/v2/currencies` и `https://api.frankfurter.dev/v2/rates?base=EUR&quotes=USD`

Для погоды и валют используются **два разных внешних поставщика API** (Open-Meteo и Frankfurter), без ключей.

## Проверка перед сдачей

1. Добавьте/удалите/сверните каждый виджет, восстановите панель.
2. Добавьте задачи, отметьте и удалите одну, обновите страницу.
3. Найдите новый город, например Токио, проверьте отображение погоды.
4. Выберите валюты из списка, введите сумму, нажмите ⇄.
5. Перетащите карточку и обновите страницу — порядок должен сохраниться.
6. Отключите интернет, обновите страницу, проверьте ошибку и кнопку повтора.
7. Пять раз удалите и добавьте виджет — один клик должен выполнять одно действие.
8. Проверьте на телефоне и компьютере.

## Публикация

Создайте публичный репозиторий GitHub, загрузите файлы проекта, включите GitHub Pages в Settings → Pages → Deploy from a branch. Перед отправкой проверьте опубликованный сайт и API из вашей сети.


### Исправление восстановления валют
В версии 3 при первом открытии автоматически возвращается валютный виджет, если он был потерян старой версией. Последующие удаления сохраняются корректно. Для ручного восстановления есть кнопка «Восстановить панель» (сбросит задачи).


### Исправление кнопки валют
Кнопка «Курсы валют» теперь всегда действует: при наличии карточки пересоздаёт её из текущих настроек и прокручивает страницу к ней. При отсутствии — добавляет заново.


## Новые виджеты (расширенная версия)

- **Мировое время** — добавление/удаление городов, живые часы с часовыми поясами IANA, без API.
- **Чемодан** — список вещей по категориям, отметки и удаление.
- **Календарь поездок** — название, дата, заметка и обратный отсчёт до поездки.
- **Мои путешествия** — посещённые города и страны, заметки и статистика.

Все виджеты можно добавлять, сворачивать, удалять и менять местами; состояние сохраняется в `localStorage`. При первом запуске на новом устройстве открываются все семь виджетов. Если у вас уже сохранена старая панель, новые виджеты добавляются кнопками слева — прежние данные не удаляются.

**Запуск:** `index.html` можно открыть напрямую, потому что в нём находится встроенная версия JS для режима `file://`. Для разработки ES-модулей используйте Live Server и исходники в папке `js/`. При изменении модулей синхронизируйте встроенный скрипт в HTML.
